Hướng dẫn

Dùng và sửa thế nào

1. Mở trang này

Chạm đúp vào file index.html, hoặc kéo file vào Chrome/Edge. Không cần server.

2. Gập máy

Kéo thanh trượt giữa trang, hoặc bấm nút Gập / Mở máy. Gập kín sẽ hiện màn hình ngoài.

3. Mở app

Bấm icon trên màn hình. Vuốt/kéo thanh xám nhỏ ở đáy để về màn hình chính.

4. Sửa code

Mọi thứ nằm trong một file. Sửa màu, chữ trong thẻ <style> và <script>, lưu lại và F5.
